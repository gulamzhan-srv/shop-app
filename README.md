# AVTOMAG GRS SOFT — касса и учёт на телефоне

Автор: Гуламжан Саттаркулович

Бесплатное приложение для маленького магазина. Сервер (VPS) не нужен:
база хранится в телефоне (SQLite), а копия и обмен между телефонами идут
через Google Диск владельца магазина (скрытая папка приложения).

## Что умеет

| Раздел | Возможности |
|---|---|
| Вход | PIN-код при каждом входе; роль (хозяин / кассир) определяется по PIN |
| Главная | Крупная дата, день недели, месяц и год; «Обновить», «Блокировать», «Закрыть»; курсы USD, EUR, RUB (₸ за 1) и UZS (сум за 1 ₸) от Нацбанка РК |
| Аналитика (хозяин) | День / неделя / месяц / квартал / год со сравнением с прошлым таким же периодом; столбики выручки с суммой прямо на столбике; выручка, прибыль (ФИФО), поступления, расходы из кассы, остаток в кассе, долги; склад — количество и сумма, по нажатию список товаров |
| Товары | Несколько фото (камера/галерея, каждое ≤ 200 КБ), штрихкод со сканером, единица, цена, комментарий |
| Поступления | Дата, поставщик, комментарий, автор, устройство, строки (кол-во × цена = сумма), итог; каждая строка — партия ФИФО |
| Касса | Поиск по названию и штрихкоду, корзина с фото, оплата наличными / Kaspi / в долг (покупатель + дата оплаты) |
| Смена | Открытие, приход/расход денег, «Закрыть кассу» со сверкой (излишек/недостача) |
| Долги | По клиентам: полоса «оплачено / долг», сколько взял, сколько должен; приём оплаты; уведомления хозяину и кассиру 3 дня подряд до даты оплаты, пока долг не оплачен |
| Возвраты | Кассир создаёт, хозяин подтверждает: «на склад» (товар новый, снова продаётся) или «брак»; деньги наличными, Kaspi или из долга |
| Сотрудники (хозяин) | Добавить кассира/хозяина, сменить PIN, отключить |
| Google Диск | Вход в Google, автоматическая синхронизация, восстановление на новом телефоне |

## Готовый APK без установки Flutter (через GitHub, бесплатно)

1. Зарегистрируйтесь на https://github.com (если ещё нет аккаунта).
2. Справа вверху «+» → **New repository** → имя `shop-app` → выберите **Private** → **Create repository**.
3. На странице репозитория нажмите **uploading an existing file**, перетащите в окно
   **всё содержимое** распакованной папки `shop_app` (папки `lib`, `tool`, `.github` и файлы
   `pubspec.yaml`, `README.md`) → **Commit changes**.
   Папку `.github` в Windows может быть не видно — включите «Показывать скрытые элементы»
   во вкладке «Вид» проводника.
4. Откройте вкладку **Actions** — сборка «Собрать APK» начнётся сама (5–10 минут).
5. Когда появится зелёная галочка, откройте вкладку **Releases** (справа на главной странице
   репозитория) → **shop-app.apk** → скачайте и установите на телефон.
   Android попросит разрешить установку из неизвестных источников — разрешите.

Если сборка красная — откройте её, нажмите на шаг с красным крестиком и пришлите текст ошибки.
Каждая новая загрузка кода собирает новый APK; он ставится поверх старого, данные сохраняются.

Репозиторий должен быть **Private**: в `tool/` лежит ключ подписи приложения.

## Установка (один раз)

1. **Flutter.** Установите Flutter и Android Studio:
   https://docs.flutter.dev/get-started/install/windows/mobile
   Проверка: `flutter doctor` (всё должно быть зелёным, кроме iOS/Chrome).
2. **Проект.** Распакуйте архив, откройте папку `shop_app` в командной строке и выполните:
   ```
   flutter create --platforms=android --org kz.grs .
   dart run tool/setup_android.dart
   flutter pub get
   ```
   `setup_android.dart` сам впишет нужные разрешения (интернет, камера, уведомления)
   и настройки сборки. Ваши файлы в `lib/` при этом не перезаписываются.
3. **Запуск.** Подключите телефон по USB (включите «Отладку по USB») и выполните `flutter run`.
4. **Готовый файл для установки (APK):** `flutter build apk --release` →
   файл `build/app/outputs/flutter-apk/app-release.apk` можно отправить на любой телефон.

## Настройка входа Google (для синхронизации)

Без этого шага всё работает, кроме Google Диска. Делается один раз для приложения.

1. Откройте https://console.cloud.google.com, создайте проект (например, «Магазин»).
2. «APIs & Services» → «Library» → найдите **Google Drive API** → «Enable».
3. «OAuth consent screen»: тип **External**, название приложения, ваш e-mail.
   В «Test users» добавьте Google-аккаунты магазинов (пока приложение «в тестировании»,
   войти могут только они; позже можно нажать «Publish app»).
4. Приложение подписывается постоянным ключом `tool/release.jks`. Его отпечаток SHA-1:
   ```
   6A:8E:33:CE:D5:A2:21:15:17:2B:B5:38:6D:AC:C6:F4:37:04:2A:98
   ```
5. «Credentials» → «Create credentials» → «OAuth client ID» → тип **Android**:
   - Package name: `kz.grs.shop_app`
   - SHA-1: из шага 4
6. Готово — в приложении «Google Диск» → «Войти в Google».

## Как работает синхронизация

- Любое изменение (продажа, товар, оплата…) записывается в журнал на телефоне.
- Через несколько секунд после изменения и каждые 3 минуты телефон отправляет
  свои изменения в скрытую папку на Google Диске и забирает изменения других телефонов.
- Если одна запись изменена на двух телефонах, остаётся более позднее изменение.
- Остатки товара не «перезаписываются», а считаются из продаж и поступлений,
  поэтому два кассира могут продавать одновременно, даже без интернета.
- **Новый телефон:** установите приложение → «Восстановить из Google Диска» →
  выберите тот же Google-аккаунт → всё появится, вход по старым PIN-кодам.
- Важно: на всех телефонах магазина — **один и тот же Google-аккаунт**.

## Файлы проекта

| Папка / файл | Что внутри |
|---|---|
| `lib/main.dart` | Запуск: база, уведомления, синхронизация, первый экран |
| `lib/db/database.dart` | Таблицы, обновления базы по версиям, список синхронизируемых таблиц |
| `lib/db/repo.dart` | Запись в базу со служебными полями и журналом изменений |
| `lib/services/` | Логика: вход, товары, фото, поставщики, поступления, ФИФО, смены, продажи, покупатели, долги, уведомления, возвраты, аналитика, курсы, синхронизация |
| `lib/screens/` | Экраны приложения |
| `lib/ui/` | Стеклянный стиль, клавиатура PIN, выбор товара, форматы чисел и дат |
| `tool/setup_android.dart` | Настройка Android-части после `flutter create` |

## Если что-то не так

- Ошибка при `flutter run` — пришлите текст ошибки целиком.
- «Не удалось войти» в Google: проверьте Package name и SHA-1 в шаге 5, включён ли Google Drive API
  и добавлен ли аккаунт в «Test users».
- Курсы не показываются — нет интернета; будут показаны последние сохранённые.
